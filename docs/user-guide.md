# User Guide

1. Open the recorder in a supported browser.
2. Enter pseudonymous Participant Code, Session Code, and Protocol.
3. Connect the Mendi.
4. Verify device status.
5. Start recording.
6. Add markers during the experiment.
7. Stop recording.
8. Preserve the generated session files.
9. Import the session into the separate Analyzer when analysis is required.

Do not enter direct personal identifiers.
