# Hardware Validation Checklist

Before declaring the recorder production-ready, validate on the physical Mendi V4 unit:

- BLE connection
- service discovery
- device information
- ABB1 continuous notifications
- ABB1 packet structure
- actual notification timing
- ABB4 telemetry
- ABB5 diagnostics
- ABB6 behavior
- battery behavior
- disconnect/reconnect
- raw packet preservation

Unknown behavior must be recorded as unknown, not guessed.
